## 🔍 How to install
###  1. Clone the repository
```
 git clone https://github.com/AsustelGames/hyprland-setup /etc/nixos
```
### 2. Rebuild the system
```
 sudo nixos-rebuild switch --flake /etc/nixos#laptop
```
