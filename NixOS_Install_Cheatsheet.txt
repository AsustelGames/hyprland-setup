1. partition in cfdisk
2. make filesystem
3. mount (First mount Root then everything else)

Name  Partition type       Make filesystem command           Mount command

Boot: EFI System          | mkfs.fat -F 32 -n boot /dev/... | mount --mkdir -o umask=077 /dev/disk/by-label/boot /mnt/boot
Root: Linux root (x86-64) | mkfs.ext4 -L nixos /dev/...     | mount /dev/disk/by-label/nixos /mnt
Home: Linux home          | mkfs.ext4 -L home /dev/...      | mount --mkdir /dev/disk/by-label/home /mnt/home
Swap: Linux swap          | mkswap -L swap /dev/...         | swapon /dev/...


1. From scratch installation
2. From repo installation


# 1. Installation from scratch 
nixos-generate-config --root /mnt

nano /mnt/etc/nixos/configuration.nix
-> configure system

nixos-install


# 2. Installation from git repo 
git clone https://github.com/AsustelGames/hyprland-setup /mnt/etc/nixos

# Replace <host> with an actual host from /etc/nixos/hosts
nixos-generate-config --root /mnt --dir /mnt/etc/nixos/hosts/<host>

# Stop nixos from complaining about git changes
cd /mnt/etc/nixos
git add -N .
cd
 
# Replace <host> with an actual host from /etc/nixos/hosts
nixos-install --root /mnt --flake /mnt/etc/nixos#<host> --impure


nixos-enter --root /mnt -c 'passwd asustel'

reboot
