1. partition in cfdisk
2. make filesystem
3. mount (First mount Root then everything else)

Name  Partition type       Make filesystem command           Mount command

Boot: EFI System          | mkfs.fat -F 32 -n boot /dev/... | mount --mkdir -o umask=077 /dev/disk/by-label/boot /mnt/boot
Root: Linux root (x86-64) | mkfs.ext4 -L nixos /dev/...     | mount /dev/disk/by-label/nixos /mnt
Home: Linux home          | mkfs.ext4 -L home /dev/...      | mount --mkdir /dev/disk/by-label/home /mnt/home
Swap: Linux swap          | mkswap -L swap /dev/...         | swapon /dev/...
